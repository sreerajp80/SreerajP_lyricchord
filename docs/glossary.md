# Glossary — LyricChord

The app's own terms and the one approved word for each in Malayalam and Sanskrit, so the same
English term is always translated the same way (engineering standard §8.5). Read this before
writing or reviewing any Malayalam or Sanskrit string.

**Read first**

- [../CLAUDE.md](../CLAUDE.md) — localization rules.
- [guidelines/language_packs/sanskrit_malayalam.md](guidelines/language_packs/sanskrit_malayalam.md)
  §4.4 — the shared UI glossary (Save, Delete, Settings, Import, Export …). Use that one first;
  this file adds only the music and app terms it does not have.

---

## 1. Status

> **Every Malayalam and Sanskrit term below is a draft written by an AI agent and needs
> native-reader review** before any release ships Malayalam or Sanskrit (language pack §4.4,
> review rule). Change a term here first, then in the ARB files.

Rules that apply to every row:

- Sanskrit: pure Sanskrit, never Hindi; nominal form for titles and labels, polite `-ताम्`
  imperative for buttons (language pack §4.1).
- Malayalam: natural Malayalam; an established music loanword (for example കോർഡ്) is allowed
  where musicians use it (language pack §4.2).
- Names stay as they are in every language: LyricChord, AirQR, ChordPro, PDF, BPM.

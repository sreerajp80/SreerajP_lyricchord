# Change Log: Add PDF page margin to prevent text clipping

**Plan:** [plans/20260808_193049_pdf-margin.md](../plans/20260808_193049_pdf-margin.md)

## Summary of Changes

Added a 20 pt (~7 mm) margin to PDF page export via CSS `@page { margin: 20pt; }`. This prevents the starting text of lyric lines from rendering at x=0, y=0 and being cut off by physical printer margins during paper printing.

## Details of Changes

- `lib/services/pdf_export_service.dart`: Replaced `@page { margin: 0; }` with `@page { margin: 20pt; }` in CSS generation.
- `test/services/pdf_export_service_test.dart`: Updated unit test assertion to verify `@page { margin: 20pt; }`.

## Verification

- `flutter analyze`: Clean (zero errors/warnings).
- `flutter test`: Passed all unit tests.

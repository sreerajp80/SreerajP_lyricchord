# Change log: Beautiful app icon for LyricCord

**Implements plan:** [plans/20260722_063734_app-icon.md](../plans/20260722_103734_app-icon.md)
**Date:** 2026-07-22

## What changed

Replaced the default Flutter launcher icon with a custom LyricCord icon.

### Design

- **Concept:** a guitar **chord diagram** (fretboard grid with three finger
  dots) plus an **eighth note**, in near-white, on a rounded squircle with a
  diagonal **violet gradient** (bright `#7C63C7` top-left to deep `#2A1259`
  bottom-right). Colours match the app palette in
  `lib/theme/app_colors.dart`.
- The art is drawn at 4x supersample and downsampled with LANCZOS for crisp,
  anti-aliased edges.

### Files added

- `tool/generate_icon.py` — Python (Pillow + numpy) script that draws the
  icon and writes the two master PNGs. Build-time developer tool only.
- `assets/icon/app_icon.png` — 1024x1024 full-bleed master (used for iOS and
  legacy Android, and as the base image).
- `assets/icon/app_icon_foreground.png` — 1024x1024 transparent foreground for
  the Android adaptive icon.

### Files changed

- `pubspec.yaml` — added `flutter_launcher_icons: ^0.14.4` to
  `dev_dependencies` and a `flutter_launcher_icons` config block
  (android + ios, `min_sdk_android: 24`, adaptive background `#4F378B`,
  adaptive foreground, `remove_alpha_ios: true`).

### Files regenerated by `dart run flutter_launcher_icons` (not hand-edited)

- `android/app/src/main/res/mipmap-*/ic_launcher.png` (all densities)
- `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` (adaptive icon)
- `android/app/src/main/res/drawable-*/ic_launcher_foreground.png`
- `android/app/src/main/res/values/colors.xml` (new — adaptive background
  colour)
- `ios/Runner/Assets.xcassets/AppIcon.appiconset/*` (full icon set)

## How to regenerate

```bash
python tool/generate_icon.py        # redraw the master PNGs
dart run flutter_launcher_icons     # regenerate platform icons
```

## Verification

- `flutter analyze` — no issues.
- `flutter test` — all 201 tests pass.
- Visually confirmed the 1024 master and a composited adaptive-icon preview
  (foreground stays inside the safe zone).

## Notes

- Offline hard rule respected: Pillow, numpy, and flutter_launcher_icons are
  build-time only; no runtime dependency, no network, no new permission.
- The icon PNGs are not added to the Flutter `assets:` bundle (they are used
  only to generate launcher icons). If the icon is later wanted inside the app
  (e.g. the About screen), add `assets/icon/` to `pubspec.yaml`.

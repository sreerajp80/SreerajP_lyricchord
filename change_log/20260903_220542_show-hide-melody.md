# Show / hide melody in the performance screen

Implements [plans/20260903_214535_show-hide-melody.md](../plans/20260903_214535_show-hide-melody.md).

## What changed

- **`lib/providers/performance_provider.dart`** — `PerformanceSettings` now has
  `showMelody` (starts on), carried through `copyWith`, `==`, `hashCode` and
  `toString`. New `toggleMelody()` on the notifier. Like `showChords`, this is
  view state only: it is not saved, so every song opens with the melody shown.
- **`lib/widgets/chord_sheet_view.dart`** — new `showMelody` parameter. When it
  is false a `{melody}` line is dropped completely, so the lyrics close up
  instead of leaving a gap. Swaram passages and swara markers written as chords
  are untouched — those still follow **Show chords**.
- **`lib/widgets/transpose_sheet.dart`** — a **Show melody** switch under
  **Show chords**, with the note "Full screen never shows the melody". It is
  only built when the new `showMelodyToggle` flag is set, so a song with no tune
  does not get a switch that does nothing. `showTransposeSheet` takes the same
  flag.
- **`lib/screens/song_performance_screen.dart`** —
  - the sheet is drawn with `showMelody: settings.showMelody && !stageMode`, so
    full screen (Stage Mode) never draws melody rows and leaving it restores
    whatever the switch says;
  - `_stopMelodyIfHidden` stops a tune that is still playing when its row goes
    off screen (switch turned off, or full screen entered), done after the frame
    so no provider is written during build;
  - the overflow menu passes `showMelodyToggle`, worked out by checking the
    song's lyrics for a `{melody}` line.
- **`lib/screens/help/help_content.dart`** — the Melody Lines topic now says
  where the switch is and that full screen never draws the rows.

## Tests

- `test/providers/performance_provider_test.dart` — the new default, the toggle,
  and `resetAll`.
- `test/widgets/chord_sheet_view_test.dart` — the melody row is drawn when on
  and gone when off, with the lyrics still there.
- `test/screens/song_performance_screen_test.dart` — the switch only appears for
  a song with a tune; turning it off drops the rows; full screen never draws
  them.

`flutter analyze` is clean and the whole suite passes.

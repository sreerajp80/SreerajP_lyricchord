## What changed

LyricCord can now write and change songs. The `/new` and `/song/:id/edit`
routes open a real editor instead of the "not built yet" card.

### New files

| File | What it does |
|------|--------------|
| `lib/services/chord_suggestion_service.dart` | Pure logic. Reads a key (`C`, `Am`, `Bb`, `F#m`, `d minor`) and returns the chords that key normally uses. Also holds the sharp and flat note tables, which Phase 4's transposer will share. |
| `lib/core/utils/chord_insert.dart` | `insertChord(TextEditingValue, chord)` — puts `[Chord]` at the caret, replaces a selection, or appends when the field was never focused. A plain function, so it is unit tested without a widget. |
| `lib/providers/song_editor_provider.dart` | `SongDraft` (the unsaved song) and `SongEditorNotifier`. Auto-disposed family keyed on the song id, with `0` meaning "new song". |
| `lib/screens/song_editor_screen.dart` | The editor page. |
| `lib/widgets/chord_inserter_bar.dart` | The Quick Chord Inserter: scrolling chord chips plus a **Custom** chip with a small dialog. |
| `lib/widgets/song_meta_fields.dart` | Title / Artist / Key / BPM block. BPM accepts digits only, up to 3. |
| `test/services/chord_suggestion_service_test.dart` | Major, minor, sharp and flat keys, and unreadable keys. |
| `test/providers/song_editor_provider_test.dart` | Insert-at-cursor, draft defaults, validation, create and update. |
| `test/screens/song_editor_screen_test.dart` | Type a title, tap a chord, add a custom chord, save, and cancel. |

## How it behaves

- **New song** starts blank, in the key of C at 120 BPM.
- **Chord suggestions follow the key as it is typed.** Major keys offer
  I, ii, iii, IV, V, vi, V7 and ♭VII; minor keys offer i, ii°, ♭III, iv, v,
  ♭VI, ♭VII and the major V7. Degrees musicians name with a flat are spelled
  with a flat, so C major offers `Bb`, not `A#`.
- **Custom chords** are added to the toolbar for the session and inserted right
  away. Blank text and repeats are ignored.
- **Forgiving validation** (hard rule 4 — never fight the user):
  - a blank title saves as `Untitled Song`,
  - a blank key saves as `C`,
  - a BPM that is missing, not a number, or outside 20–300 saves as 120,
  - an unreadable key still gives a usable chord toolbar (C major).
- **Cancel** leaves at once when nothing changed, and asks "Discard changes?"
  when there are unsaved edits. The system back gesture goes through the same
  check.
- **Save** writes through `SongRepository` (create or update), keeps the star
  and picks up a fresh timestamp, then leaves the editor and selects the song
  in the list pane.

## Rules followed

- No new packages, so the app stays fully offline.
- Layers kept: the widget knows no SQL and no chord theory; the service knows
  no UI; the provider is the only glue.
- `flutter analyze` clean, `flutter test` green, `dart format .` run.

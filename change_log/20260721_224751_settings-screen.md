# Change log: Settings screen with Import/Export, Themes, Chords, About

**Plan:** `plans/20260721_222752_settings-screen.md`

## What changed

### New Settings area
- `lib/screens/settings_screen.dart` — a Settings screen with 4 cards:
  Import/Export, Themes, Chords, and About. Opened from a gear icon in the
  song-list app bar. Back (arrow or system back) returns to the song list.
- `lib/screens/import_export_screen.dart` — the "Import ChordPro" flow moved
  here from the song-list overflow menu, unchanged in behaviour. An info tile
  points to the per-song share menu for export.
- `lib/screens/theme_settings_screen.dart` — System / Light / Dark choices as
  radio tiles (using the new `RadioGroup` API; the old `groupValue` way is
  deprecated in this Flutter version). Saves through the existing
  `themeModeProvider`.
- `lib/screens/chord_settings_screen.dart` — the user can add custom chord
  notations (e.g. `Cmaj7`, `D/F#`) and remove them. Input is trimmed, capped
  at 12 characters, and repeats are refused with a `SnackBar`.

### Custom chords wiring
- `lib/providers/custom_chords_provider.dart` — new. Saves the chord list in
  `shared_preferences` (key `custom_chords`), same pattern as the theme mode.
- `lib/core/constants/app_constants.dart` — added `prefCustomChords`.
- `lib/providers/song_editor_provider.dart` — `SongDraft` got
  `chordSuggestionsWith(saved)`: key chords first, then saved custom chords,
  then this session's chords, no repeats.
- `lib/screens/song_editor_screen.dart` — the chord bar now watches
  `customChordsProvider`, so saved chords always appear in the editor.

### Menu clean-up
- `lib/screens/song_list_screen.dart` — the overflow menu (Import / themes /
  About) is replaced by a single Settings icon button. The moved import code
  was removed.
- `lib/screens/song_performance_screen.dart` — its overflow menu's theme
  items and About entry are replaced by one "Settings" entry. **Small
  deviation from the plan:** the plan missed that this screen also used the
  theme menu; export items there are untouched.
- `lib/widgets/theme_mode_menu.dart` — deleted (no longer used).
- `lib/core/router/app_router.dart` — new routes: `/settings`,
  `/settings/import-export`, `/settings/themes`, `/settings/chords`.

### Tests
- New: `test/screens/settings_screen_test.dart` (cards, navigation, back,
  theme save), `test/screens/chord_settings_screen_test.dart` (add, refuse
  repeats, delete, persistence), and
  `test/providers/custom_chords_provider_test.dart` (load, add, remove,
  length cap, no dupes).
- Updated: `test/screens/song_editor_screen_test.dart` now overrides
  `sharedPreferencesProvider` and covers saved chords showing in the toolbar
  without doubling; `test/screens/song_list_screen_test.dart` checks the new
  Settings button.

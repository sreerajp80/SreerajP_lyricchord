# Change Log: Fix Chord Color Visibility in Dark and Light Themes

**Plan:** [plans/20260723_181513_fix_chord_colors.md](../plans/20260723_181513_fix_chord_colors.md)

## Summary
Fixed poor contrast and illegibility of chord text on song sheets in both Light and Dark themes.

## Changes Made
1. `lib/theme/app_theme.dart`:
   - Updated `_lightScheme.secondary` to `AppColors.lightPrimary` (`0xFF6750A4`).
   - Updated `_darkScheme.secondary` to `AppColors.darkPrimary` (`0xFFD0BCFF`).
2. `lib/widgets/chord_sheet_view.dart`:
   - Set `chordStyle` text color to `theme.colorScheme.primary` for bold, vibrant high-contrast chord badges.
3. `test/widgets/chord_sheet_view_test.dart`:
   - Added widget tests validating chord text color in both Light and Dark modes.

## Verification
- Verified all static analysis (`flutter analyze`) produces 0 issues/warnings.
- Verified all unit and widget tests (`flutter test`) pass cleanly.

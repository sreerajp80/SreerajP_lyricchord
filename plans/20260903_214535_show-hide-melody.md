# Show / hide melody in the performance screen

**Status:** completed

## Issue

A song with `{melody}` lines always draws the melody rows (the beat grid with
the play button) under each lyric line. There is no way to turn them off.

Two things are needed:

1. A **Show melody** switch in the performance view, next to the existing
   **Show chords** switch, so the player can read plain lyrics when the tune
   rows get in the way.
2. In **full screen (Stage Mode)** the melody rows must never be drawn. Stage
   Mode is for performing: the beat grid takes vertical space and its play
   button cannot be tapped safely while playing.

## Plan for the fix

1. **State.** `PerformanceSettings.showMelody` is view state only, like
   `showChords` — never stored in the database, so every song opens with the
   melody shown. `toggleMelody()` flips it. `resetAll()` already returns the
   whole object to its defaults, so it needs no change.

2. **Drawing.** `ChordSheetView` takes `showMelody`. In its line loop, a line
   whose `kind` is `melody` is skipped when `showMelody` is false. Only
   `{melody}` rows are affected — a swaram passage line (`ChordLineKind.swaram`)
   and the swara markers written as chords stay, because those are part of the
   written notation, not the playable tune. Hiding those stays with the existing
   **Show chords** switch.

3. **Full screen.** The performance screen already builds the sheet with a
   `stageMode` flag. It will pass
   `showMelody: settings.showMelody && !stageMode`, so Stage Mode never draws
   melody rows whatever the switch says, and leaving Stage Mode brings them
   back exactly as the switch left them.

4. **Stop the sound.** The melody player is a provider, so a tune could keep
   playing after its row is removed. When the melody rows are hidden — the
   switch turned off, or Stage Mode entered — the screen calls
   `melodyPlayerProvider.notifier.stop()`. This is done after the frame, not
   during `build`, so no provider is written while widgets are building.

5. **The switch.** It sits in the Performance-controls bottom sheet, under
   **Show chords**, worded **Show melody**. It only appears for a song that has
   at least one melody line, so a song with no tune does not get a switch that
   does nothing.

6. **Checks.** `flutter analyze` must stay clean, `flutter test` must pass, and
   `dart format .` is run before finishing.

## Not doing

- No change to how melody is exported, shared or printed.
- No new setting saved to disk — the switch resets when the song is closed,
  matching **Show chords**.

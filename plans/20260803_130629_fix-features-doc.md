## What is wrong

I checked `docs/features.md` against the real source code. It has three factual
errors and several missing details:

1. **Wrong contact email.** The doc says `sreerajp80@zoho.com`. The real email,
   read from `assets/config/app_config.json:8` (which is what the About screen
   actually shows), is `sreerajp@zohomail.in`.
2. **Wrong theme colors.** The doc says the palette is `#6750A4` (light) /
   `#D0BCFF` (dark). The real primary colors, in `lib/theme/app_colors.dart`,
   are `#0052CC` (light, blue) and `#FFD54F` (dark, amber). `#D0BCFF` is only
   used for a floating-action-button background, not the main theme color.
3. **Wrong transpose range.** The doc says transposition goes from -12 to +12
   semitones. The code (`lib/providers/performance_provider.dart:73`) stops at
   -11 and +11. Going a full 12 semitones would just repeat the same key, so
   the code intentionally stops one short.

## What is missing

These real features exist in the code but are not mentioned in the doc:

4. Settings hub structure — how General Settings groups Import, Import
   Settings, Metronome, Themes, Chords, Fonts, Help, About into one menu
   (`lib/screens/settings_screen.dart`, `general_settings_screen.dart`).
5. Custom chord limits — custom chord entries are capped at 12 characters and
   saved to on-device preferences (`lib/providers/custom_chords_provider.dart`).
6. Home shell split-view details — the exact tablet layout behavior
   (`lib/screens/home_shell.dart`).
7. Key-aware chord suggestion fallback — an unreadable song key silently falls
   back to C major (`lib/services/chord_suggestion_service.dart`).
8. One-time Stage Mode help — the gesture help overlay is shown once and then
   remembered so it doesn't show again (`lib/core/constants/app_constants.dart`).
9. Startup version check — the app quietly checks its own version against
   config on startup and logs a warning if they don't match (debug builds only)
   (`lib/core/config/config_service.dart`).
10. Safe file naming — exported file names are cleaned of characters that
    would break on some file systems, while keeping non-English letters (like
    Malayalam) intact (`lib/core/utils/safe_file_name.dart`).
11. Song duplication naming rule — a duplicated song is named
    "<Title> (Copy)", or "Untitled Song (Copy)" if the title was blank.
12. ChordPro short directive names — the importer also understands short forms
    like `{t}`, `{a}`, `{k}`, `{c}`, and `{tempo}` as well as the long forms
    already listed.
13. Font license screen detail — the app registers open-source font licenses
    (Noto, Manjari, Gayathri) so they show up in Flutter's built-in licenses
    page (`lib/main.dart`).

# Plan: Create a beautiful app icon for LyricCord

**Status:** completed

## Issue

The app still ships the default Flutter launcher icon (the blue Flutter logo).
LyricCord needs its own icon that matches its identity — a lyrics & chords
notebook — and its violet Material palette.

## Concept (chosen by user)

**Chord diagram + note** on a rounded squircle with a violet gradient
background:

- Background: rounded square, diagonal violet gradient using the app palette
  (deep `#4F378B`/`#6750A4` to light `#D0BCFF`).
- Foreground (white / near-white): a guitar **chord diagram** — a small
  fretboard grid (vertical strings + horizontal frets) with a few filled
  finger dots — plus a single **eighth note** placed to the upper-right.
- Clean, centered, generous padding so it reads well at small sizes and inside
  Android's adaptive-icon safe zone.

## Approach

1. **Tooling.** No ImageMagick/cairosvg available on this machine, but `pip`
   works. Install `Pillow` (image drawing only — a build-time dev tool, not an
   app dependency, so it does not touch the offline hard rules).
2. **Master image.** Write a Python script
   `tool/generate_icon.py` that draws the icon at 4x supersample (4096 px) and
   downsamples to a crisp **1024x1024 PNG** at `assets/icon/app_icon.png`.
   Also produce a **foreground-only** transparent PNG
   `assets/icon/app_icon_foreground.png` (the chord+note art on a transparent
   field, padded for the adaptive safe zone) for Android adaptive icons.
3. **Generate platform icons.** Add `flutter_launcher_icons` to
   `dev_dependencies` and an `flutter_launcher_icons` config (image_path,
   adaptive_icon_background = a solid violet, adaptive_icon_foreground,
   min_sdk_android 24, iOS true). Run it to regenerate all Android `mipmap-*`
   PNGs, the adaptive `ic_launcher.xml`, and iOS `AppIcon.appiconset`.
4. **Assets.** Add `assets/icon/` to `pubspec.yaml` assets only if we want the
   PNG available at runtime (e.g. About screen). Optional — will confirm; by
   default the icon is only used as the launcher icon and does not need to be a
   bundled asset.
5. **Verify.** `flutter pub get`, run the generator, `flutter analyze`, and
   `flutter test` to confirm nothing broke. Visually confirm the generated
   1024 master.

## Files to be changed / added

- `tool/generate_icon.py` — **new**, the icon drawing script.
- `assets/icon/app_icon.png` — **new**, 1024 master (full bleed).
- `assets/icon/app_icon_foreground.png` — **new**, adaptive foreground.
- `pubspec.yaml` — add `flutter_launcher_icons` dev dep + config block.
- Regenerated launcher icons (tool output, not hand-edited):
  - `android/app/src/main/res/mipmap-*/ic_launcher.png`
  - `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` (+ background/
    foreground drawables)
  - `ios/Runner/Assets.xcassets/AppIcon.appiconset/*`

## Notes / constraints honored

- Fully offline: Pillow and flutter_launcher_icons are build-time only; no
  runtime network, no new app runtime dependency, no new permission.
- Palette matches `lib/theme/app_colors.dart`.
- No generated file is hand-edited; icons come from the tool.

## Out of scope

- Splash screen art, monochrome themed-icon variant (Android 13 tint) — can be
  a follow-up if wanted.

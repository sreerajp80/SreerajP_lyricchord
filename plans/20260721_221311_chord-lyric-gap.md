# Reduce the gap between chords and lyrics

**Status:** completed

## The issue

In the performance view, there is too much empty space between a chord
symbol and the lyric line below it. The original Android app (see the
user's screenshot) keeps the chord almost touching its lyric line.

The gap comes from two places in
`lib/widgets/chord_sheet_view.dart`:

1. **The chord slot is taller than the chord text.** Each chunk reserves
   a box of height `chordStyle.fontSize * 1.4` for the chord
   (line 174). The chord text itself only needs about
   `fontSize * 1.1` (its own line height), so the extra `0.3 ×`
   font size becomes dead space *below* the chord, right where the gap
   shows.
2. **The lyric line height adds leading above the lyric.** The lyric
   style uses `height: 1.35` (line 37). Flutter puts half of that extra
   leading *above* the text, widening the gap further.

## Files to change

- `lib/widgets/chord_sheet_view.dart` — the only code change.
- `test/...` — run the existing widget tests; update only if a test
  asserts on the old sizes (a quick search shows no test pins these
  numbers, so likely no test change).

## The fix

1. Shrink the chord slot from `chordStyle.fontSize! * 1.4` to
   `chordStyle.fontSize! * 1.1`, so the box is exactly as tall as the
   chord text and holds no dead space.
2. Reduce the lyric `height` from `1.35` to `1.2`. This trims the
   leading above the lyric while keeping enough breathing room
   between stacked lines.
3. Keep the 2 px bottom padding between sheet lines as-is, so verses
   stay readable.

Then run `flutter analyze` and `flutter test`, and check the result in
the app.
